# Portal Apoderados — Escuela Villa Las Peñas

Aplicación web progresiva (PWA) para que los apoderados de la **Escuela Villa Las Peñas** puedan consultar:

- 📊 **Calificaciones** de sus hijos por asignatura y semestre
- ⏰ **Registro de atrasos** con historial cronológico

## Acceso

🌐 **[Abrir Portal](https://pipexstar.github.io/portal-apoderados-vlp/)**

## Características

- ✅ Funciona en cualquier celular (Android e iPhone)
- ✅ Se puede instalar en la pantalla de inicio como una app nativa
- ✅ Multi-hijo: vincula a todos tus hijos con sus RUT
- ✅ Datos en tiempo real desde la base de datos del colegio
- ✅ 100% gratuito y seguro

## Uso

1. Abre el enlace desde tu celular
2. Ingresa el **RUT del estudiante**
3. El sistema verifica que el alumno esté matriculado
4. Accede a sus calificaciones y atrasos al instante
